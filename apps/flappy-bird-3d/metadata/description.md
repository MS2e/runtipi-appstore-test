# Flappy Bird 3D

Ein spektakulärer 3D-Flappy-Bird-Klon für den Browser, gebaut mit Three.js und Vite.

## Features

- 🐦 3D-Bird mit realistischer Schwerkraft- und Sprung-Physik
- 🏗️ Prozedural generierte Röhren mit Kollisionsdetektion (10% verkleinerte AABB)
- ✨ Unreal Bloom Post-Processing
- 🌈 Chromatische Aberration Shader
- 💫 4 Partikelsysteme (Jump, Score, Collision, Death)
- 🔦 3-Punkt-Dynamikbeleuchtung mit PCFSoft Schatten
- 🏙️ Animierte Skyline im Hintergrund
- 📱 Responsive Design (Mobile + Desktop)
- 💾 Hoher Score im localStorage persistiert
- 🎮 Unterstützt Tastatur (Space/ArrowUp), Maus und Touch

## Installation

Die App wird als Docker-Container bereitgestellt und über den Runtipi-Nginx-Proxy bereitgestellt. Nach der Installation über das Runtipi-Dashboard ist sie unter der Standard-URL erreichbar.

## Anforderungen

- Runtipi mit Docker-Unterstützung
- Mindestens 256MB RAM verfügbar
