⚙️ Konfiguration

TradingAgents wird über RunTippi Settings konfiguriert:

  • TRADINGAGENTS_LLM_PROVIDER — LLM Provider (openai, anthropic, google, deepseek, openrouter)
  • TRADINGAGENTS_API_KEY — API Key des gewählten Providers
  • TRADINGAGENTS_DEFAULT_MODEL — Default Modell (z.B. gpt-5.4)
  • TRADINGAGENTS_INITIAL_TICKER — Voreingestellter Ticker

🚀 CLI-Nutzung

Direkter Zugriff via SSH/Terminal auf dem RunTippi-Host:

tradingagents          # Interaktiver Modus
python -m cli.main     # Alternative

Die Analyse-Results werden gespeichert unter ~/.tradingagents/logs/
